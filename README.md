# SQL Practice & Query Portfolio

## 📌 Project Overview

This repository contains my SQL learning journey, practical exercises, and hands-on query practice using MySQL Workbench.

I have practiced SQL concepts from beginner to advanced levels by writing queries, solving database-related problems, and performing data retrieval, filtering, manipulation, and analysis.

The main objective of this repository is to strengthen my SQL knowledge and develop practical database querying and problem-solving skills.

## 🎯 Learning Objectives

- Build a strong foundation in SQL.
- Understand relational database concepts.
- Write efficient SQL queries.
- Perform data manipulation and retrieval.
- Solve real-world database problems.
- Improve analytical and problem-solving skills.

## 📚 SQL Concepts Covered

### 🟢 Beginner Level
- Introduction to SQL
- Database and Table Creation
- CREATE, ALTER, DROP
- INSERT, UPDATE, DELETE
- SELECT Statements
- WHERE Clause
- DISTINCT
- ORDER BY
- LIMIT
- AND, OR, NOT Operators
- BETWEEN, IN, LIKE
- NULL Values

### 🟡 Intermediate Level
- Aggregate Functions (COUNT, SUM, AVG, MIN, MAX)
- GROUP BY
- HAVING
- SQL Joins
  - INNER JOIN
  - LEFT JOIN
  - RIGHT JOIN
  - CROSS JOIN
- Primary Key and Foreign Key
- Constraints
- CASE Statements
- String Functions
- Date and Time Functions

### 🔴 Advanced Level
- Subqueries
- Correlated Subqueries
- Common Table Expressions (CTE)
- Window Functions
- ROW_NUMBER()
- RANK()
- DENSE_RANK()
- PARTITION BY
- Views
- Indexes
- Query Optimization
